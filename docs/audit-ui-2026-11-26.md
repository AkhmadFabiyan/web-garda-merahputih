## B. Kenapa terasa "AI slop" — ditangani dengan arah "Garda Bergerak" (lihat `UI_UX_RULES.md` 3.6; percobaan Prasasti Nuswantara dibatalkan)

**Temuan utama:** situs ini **selama ini tampil dengan Times New Roman** karena bug. Variabel font `next/font` dipasang di `<body>`, sedangkan `--font-body` di `:root` merujuk variabel itu. Bug ini sudah diperbaiki, jadi Inter dan Poppins sekarang benar-benar termuat. Masalahnya, Inter + Poppins + gradasi + kartu kaca adalah kombinasi template AI paling umum. Saat masih tampil serif, gaya template itu tertutupi.

Ciri template AI (kit 12.3) yang ada di kode:

| Ciri | Bukti di kode | Lokasi contoh |
|---|---|---|
| Font Inter/Poppins tanpa alasan brand | `layout.tsx` memuat Inter + Poppins | `src/app/layout.tsx` |
| Hero berpola template: badge kecil, judul besar dua baris, subjudul, dua tombol, ilustrasi | Persis pola ini | `Hero.tsx` |
| Teks judul bergradasi + glow | 2× `background-clip: text`, 11× `drop-shadow`/`text-shadow`/glow | `Hero.module.css` `.highlight` |
| Glassmorphism dan blur di banyak tempat | 26× `backdrop-filter` | kartu Quick Access, navbar, modal |
| Bayangan besar dan kartu melayang di semua elemen | 102× `box-shadow`, 46× efek hover `translateY(-…)` | hampir semua kartu |
| Radius tidak konsisten | 12 nilai `border-radius` berbeda (0.125 – 6.25rem) | seluruh CSS |
| Tombol gradasi merah–oranye | 14 file memakai `--gradient-primary` | tombol, badge, chip |
| Banyak animasi | 34 `@keyframes` (fadeIn, slideUp, shimmer, pulse, float, …) | seluruh CSS |
| Kotak ikon membulat yang diulang di setiap section | Quick Access, Info Garda | `QuickAccess`, `InfoGarda` |
| Penamaan "Premium" di token | "Premium Color Palette", "Premium Shadows", "Premium Card" | `globals.css` |

Masalah lain yang ada di versi lama maupun sekarang:
- **Ikon Info Garda semuanya placeholder.** Keempat file `public/assets/icons/*.svg` identik (md5 sama) dan tampil sebagai kotak kuning.
- **Gambar galeri "Ikuti Kami" rusak.** Yang tampil hanya teks alt "Galeri PKKMB 1/2", karena URL `unesa.ac.id` ditolak (403).
- **Kontras teks sekunder** belum diukur (kit menargetkan ≥ 7:1 untuk teks isi).

## C. Rekomendasi (perlu keputusan)

1. **Tentukan arah visual dulu** (kit 12.4): tiga kata kesan dari panitia, satu elemen khas dari brand (misalnya motif "Jayantara Nuswantara", lambang garuda, atau warna merah-emas), lalu tulis sebagai satu paragraf.
2. **Font:** pilih font yang punya karakter, bukan Inter/Poppins. Contohnya serif bertema untuk judul plus sans yang rapi untuk isi.
3. **Kurangi efek:**
   - Satu skala radius (misalnya 0.5rem untuk kontrol, 1rem untuk kartu).
   - Maksimal 2 tingkat bayangan.
   - Hapus blur kaca kecuali di navbar.
   - Hapus hover-lift di kartu yang bukan tautan.
   - Animasi hanya untuk umpan balik.
4. **Gradasi** hanya untuk satu elemen khas, bukan untuk semua tombol dan badge.
5. **Perbaiki ikon Info Garda dan galeri** dengan aset asli.
